2×2 systems of equations

Two linear equations, two unknowns — x and y. Solve either by substitution or by elimination.

What is a system of equations?

A system of equations is a set of equations that share the same variables. Solving the system means finding the value of every variable that makes all the equations true at the same time.

Each equation like 2x + y = 5 represents a line. The solution to a 2×2 system is the point (x, y) where the two lines cross.

Three possible outcomes

  • One solution — the lines cross at exactly one point. This is the case you'll see throughout this site.
  • No solution — the lines are parallel and never cross. While solving, every variable cancels and you're left with a false statement, like 0 = 6.
  • Infinitely many solutions — both equations describe the same line. Every variable cancels and you're left with a true statement, like 0 = 0.

Two ways to solve

Substitution works well when one equation already has (or can easily get) a variable by itself. Elimination works well when the equations are lined up neatly and a variable can be cancelled by adding or subtracting. Both always give the same answer — pick whichever fits the numbers in front of you.

Steps for substitution

  1. Solve one equation for one variable — pick whichever variable already has a coefficient of 1 or −1, if possible.
  2. Substitute that expression into the other equation, replacing that variable everywhere it appears.
  3. Solve the resulting one-variable equation.
  4. Substitute that value back into the expression from step 1 to find the other variable.
  5. Check both original equations with your answer.

Example 1

x + 2y=7
3x − y=7
  1. Equation 1 already has x alone-ish: solve for x → x = 7 − 2y.
  2. Substitute into equation 2: 3(7 − 2y) − y = 7.
  3. Distribute and solve: 21 − 6y − y = 7 → −7y = −14 → y = 2.
  4. Back-substitute: x = 7 − 2(2) = 3.

Solution: (3, 2) — check: 3 + 4 = 7 ✓ and 9 − 2 = 7 ✓

Example 2 (negative answer)

x + 3y=11
2x − y=−13
  1. Solve equation 1 for x: x = 11 − 3y.
  2. Substitute into equation 2: 2(11 − 3y) − y = −13.
  3. Distribute and solve: 22 − 6y − y = −13 → −7y = −35 → y = 5.
  4. Back-substitute: x = 11 − 3(5) = −4.

Solution: (−4, 5) — check: 2(−4) − 5 = −13 ✓

Steps for elimination

  1. Line up the equations so like terms (x-terms, y-terms, constants) are stacked.
  2. Multiply one or both equations by a number so one variable's coefficients become opposites.
  3. Add the equations — that variable cancels out.
  4. Solve the resulting one-variable equation.
  5. Substitute the value back into either original equation to find the other variable.
  6. Check both original equations.

Example 1

3x + 2y=16
5x − 2y=16
  1. The y-coefficients are already opposites (2 and −2), so add the equations directly: 8x = 32.
  2. Solve: x = 4.
  3. Substitute into equation 1: 3(4) + 2y = 16 → 2y = 4 → y = 2.

Solution: (4, 2) — check: 5(4) − 2(2) = 20 − 4 = 16 ✓

Example 2 (needs a multiplier)

2x + 3y=−12
5x + 2y=−19
  1. To cancel y, match its coefficients to 6: multiply equation 1 by 2 → 4x + 6y = −24; multiply equation 2 by 3 → 15x + 6y = −57.
  2. Subtract the equations to eliminate y: −11x = 33 → x = −3.
  3. Substitute into equation 1: 2(−3) + 3y = −12 → 3y = −6 → y = −2.

Solution: (−3, −2) — check: 5(−3) + 2(−2) = −15 − 4 = −19 ✓

3×3 systems of equations

Three linear equations, three unknowns — x, y and z. Same two methods as before, extended by one more variable.

From lines to planes

Each equation in three variables, like x + 2y − z = 4, describes a flat plane in 3-D space instead of a line. The solution to a 3×3 system is the single point (x, y, z) where all three planes meet — assuming they meet at exactly one point, which is the case in every example and practice problem here.

The core strategy: reduce, then solve

You already know how to solve a 2×2 system. The trick for 3×3 is to use one variable's cancellation twice to shrink the problem down to a 2×2 system, solve that, then plug back in:

  1. Pick a variable to eliminate first.
  2. Combine two pairs of equations to eliminate that same variable twice — this leaves a 2×2 system in the remaining two variables.
  3. Solve that 2×2 system.
  4. Substitute both values into any original equation to find the third variable.

Steps for substitution

  1. Find the equation and variable that's easiest to isolate — ideally one with a coefficient of 1 or −1.
  2. Solve that equation for that variable in terms of the other two.
  3. Substitute that expression into the other two equations — this leaves a 2×2 system in the remaining variables.
  4. Solve the 2×2 system.
  5. Substitute both values back into the step-1 expression to find the first variable.
  6. Check all three original equations.

Worked example

x + y − z=7
2x + y + z=4
3x − 2y + z=−7
  1. Equation 1 has x alone: solve for x → x = 7 − y + z.
  2. Substitute into equation 2: 2(7 − y + z) + y + z = 4 → 14 − y + 3z = 4 → −y + 3z = −10.
  3. Substitute into equation 3: 3(7 − y + z) − 2y + z = −7 → 21 − 5y + 4z = −7 → −5y + 4z = −28.
  4. Solve the 2×2 system: from −y + 3z = −10, y = 3z + 10. Substitute: −5(3z+10) + 4z = −28 → −11z = 22 → z = −2, so y = 4.
  5. Back-substitute: x = 7 − 4 + (−2) = 1.

Solution: (1, 4, −2) — check equation 3: 3(1) − 2(4) + (−2) = 3 − 8 − 2 = −7 ✓

Steps for elimination

  1. Choose a variable to eliminate first.
  2. Combine equations 1 & 2 to eliminate that variable — call the result equation A.
  3. Combine equations 1 & 3 to eliminate the same variable — call the result equation B.
  4. Solve the 2×2 system formed by A and B.
  5. Substitute both values into any original equation to find the third variable.
  6. Check all three original equations.

Worked example

x + y + z=4
2x − y + z=8
x + 2y − z=−3
  1. Eliminate z from equations 1 & 2 (subtract eq. 1 from eq. 2): x − 2y = 4 — call this A.
  2. Eliminate z from equations 1 & 3 (add eq. 1 and eq. 3): 2x + 3y = 1 — call this B.
  3. Solve A & B: from A, x = 4 + 2y. Substitute into B: 2(4+2y) + 3y = 1 → 7y = −7 → y = −1, so x = 2.
  4. Back-substitute into equation 1: 2 + (−1) + z = 4 → z = 3.

Solution: (2, −1, 3) — check equation 2: 2(2) − (−1) + 3 = 4 + 1 + 3 = 8 ✓

Linear inequalities

Everything from a single inequality to compound, absolute-value, and two-variable graphed inequalities — including the special cases where a "solution" isn't a single point at all.

The four symbols

< less than  ·  > greater than  ·  ≤ less than or equal to  ·  ≥ greater than or equal to.

The one rule that's different from equations

Solving an inequality works exactly like solving an equation — add, subtract, multiply, divide both sides — with one exception: whenever you multiply or divide both sides by a negative number, you must flip the direction of the inequality symbol.

Quick check: 2 < 5 is true. Multiply both sides by −1 without flipping: −2 < −5 — false! Flip the symbol instead: −2 > −5 — true again.

Reading and graphing a solution

A solution like x > 3 isn't one number — it's every number bigger than 3. On a number line, a strict symbol (< or >) gets an open circle at the boundary since that number itself isn't included; an inclusive symbol (≤ or ≥) gets a filled circle. Shade the direction the solution extends.

Steps for a one-variable inequality

  1. Simplify each side — distribute and combine like terms.
  2. Move all variable terms to one side and all constants to the other.
  3. Divide both sides by the coefficient of the variable — flip the symbol if that coefficient is negative.
  4. Write the solution in inequality notation and graph it.

Example 1 — straightforward

3x − 5≤16
  1. Add 5 to both sides: 3x ≤ 21.
  2. Divide both sides by 3 (positive — no flip): x ≤ 7.

Example 2 — dividing by a negative

5 − 2x>17
  1. Subtract 5 from both sides: −2x > 12.
  2. Divide both sides by −2 — flip the symbol: x < −6.

Example 3 — no solution

4(x + 1)<4x − 9
  1. Distribute: 4x + 4 < 4x − 9.
  2. Subtract 4x from both sides: 4 < −9.
  3. This is false no matter what x is — no solution.

Example 4 — all real numbers

2(x − 3)≥2x − 10
  1. Distribute: 2x − 6 ≥ 2x − 10.
  2. Subtract 2x from both sides: −6 ≥ −10.
  3. This is true no matter what x is — all real numbers.

"And" versus "or"

An and compound inequality is true only when both conditions hold — the solution is the overlap, usually written as a single chain like −3 < x ≤ 5 and graphed as a segment between two points.

An or compound inequality is true when at least one condition holds — the solution is everything satisfying either piece, graphed as two rays shooting apart from each other.

"And" example

−7 < 3x + 2≤11
  1. Subtract 2 from all three parts: −9 < 3x ≤ 9.
  2. Divide all three parts by 3: −3 < x ≤ 3.

"Or" example

2x + 1<−5
or
3x − 4>11
  1. Solve the first: 2x < −6 → x < −3.
  2. Solve the second: 3x > 15 → x > 5.
  3. Combine with "or": x < −3 or x > 5.

Turning absolute value into a compound inequality

Absolute value measures distance from zero, so |expression| < k means the expression sits within k units of zero on both sides — rewrite it as an and: −k < expression < k.

|expression| > k means the expression is farther than k units from zero, in either direction — rewrite it as an or: expression < −k or expression > k. (The same idea applies to ≤ and ≥.)

"Less than" example

|2x − 3|≤9
  1. Rewrite as a chain: −9 ≤ 2x − 3 ≤ 9.
  2. Add 3 to all three parts: −6 ≤ 2x ≤ 12.
  3. Divide by 2: −3 ≤ x ≤ 6.

"Greater than" example

|3x + 6|>12
  1. Rewrite as two cases: 3x + 6 < −12 or 3x + 6 > 12.
  2. Solve each: 3x < −18 → x < −6  or  3x > 6 → x > 2.
Special cases: since an absolute value can never be negative, |expression| < 0 (or any negative number) has no solution, and |expression| > a negative number is true for all real numbers.

When the solution is a whole region

A linear inequality in two variables, like y < 2x + 1, isn't satisfied by a line — it's satisfied by every point on one side of a line. To graph it:

  1. Graph the boundary line as if the inequality were an equation.
  2. Make the line solid if the symbol is ≤ or ≥ (the boundary is included); dashed if it's < or > (the boundary isn't included).
  3. Pick a test point off the line — (0, 0) is easiest when the line doesn't pass through the origin.
  4. Plug the test point into the original inequality. If it's true, shade the side containing that point; if false, shade the other side.

Solid boundary: y ≤ x − 2

Test (0, 0): is 0 ≤ 0 − 2? That's 0 ≤ −2, false — so shade the side without the origin, and draw the line solid.

Dashed boundary: y > −x + 3

Test (0, 0): is 0 > 3? False — shade the side without the origin, and draw the line dashed since points on it don't count.

Systems of two-variable inequalities

When you graph more than one two-variable inequality on the same plane, the solution to the system is wherever the shaded regions overlap.

Shown: y ≤ x + 1 (solid) together with y > −2x − 1 (dashed). The darker region satisfies both at once.

Scalar & matrix multiplication

A matrix is just a rectangular grid of numbers. Here's how to scale one by a single number, and how to multiply two matrices together — both step by step, and both landing on whole numbers.

What is a matrix?

A matrix is a rectangular array of numbers arranged in rows and columns. Its size is written as rows × columns — a matrix with 2 rows and 3 columns is a "2 by 3" matrix.

4−10 27−5
a 2 × 3 matrix — 2 rows, 3 columns

Each number is called an entry, named by its row and column position. The entry in row 2, column 3 above is −5.

Scalar vs. matrix

A scalar is a single ordinary number, like 3 or −2. Multiplying a matrix by a scalar just scales every entry. Multiplying a matrix by another matrix is a different operation entirely — it combines rows of the first with columns of the second, and it isn't just "multiply matching entries."

Steps for scalar multiplication

  1. Take the scalar and multiply it by every single entry in the matrix — no entry is skipped.
  2. Keep the result in the same shape (same number of rows and columns) as the original.
  3. Watch your signs: a negative scalar flips the sign of every entry.

Example 1

3 ·
4−2 05
=
12−6 015
  1. Multiply every entry by 3: 3(4) = 12, 3(−2) = −6, 3(0) = 0, 3(5) = 15.

Example 2 (negative scalar, 2×3)

−2 ·
1−36 −402

−26−12 80−4
  1. Multiply every entry by −2, flipping each sign: −2(1) = −2, −2(−3) = 6, −2(6) = −12, −2(−4) = 8, −2(0) = 0, −2(2) = −4.

Checking compatibility first

Two matrices can only be multiplied when the number of columns in the first matches the number of rows in the second. A 2 × 3 matrix can multiply a 3 × 2 matrix (the inner 3's match) but not a 2 × 3 one. The result takes the outer dimensions — here, a 2 × 2 matrix.

How each entry is built

Entry (i, j) of the product comes from row i of the first matrix and column j of the second: multiply corresponding entries together, then add up those products.

  1. Confirm the matrices are compatible: columns of A must equal rows of B.
  2. For each entry of the result, pick a row from A and a column from B.
  3. Multiply the matching entries from that row and column, in order, then sum the products.
  4. Repeat for every row–column pairing until the whole result matrix is filled in.

Note: matrix multiplication is not commutative — swapping the order to B × A generally gives a different result, or may not even be defined.

  3. Row 2 of A times column 1 of B: −1(5) + 4(1) = −5 + 4 = −1.
  4. Row 2 of A times column 2 of B: −1(0) + 4(−2) = 0 − 8 = −8.
